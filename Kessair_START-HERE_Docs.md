# Kessair — `00_START-HERE` Drive Welcome Docs

**The one-pager that greets anyone landing in a drive: what it is, what goes where, and the rules.**

*Version 1.0 — 2026-07-02 · Pairs with: Organization Standard + Naming Cards*

---

## How to use these

Each block below is a ready-to-paste **`00_START-HERE`** doc for a drive. Create a Google Doc named `00_START-HERE` at the **root of the drive** (the `00_` pins it to the top) and paste the matching block in.

Filled below are the **highest-traffic drives** (where VAs land most). For the other companies' drives, copy the **Master** template and adjust the one-liners — same shape every time.

---

## ⬛ MASTER (blank) — copy for any drive

```
📌 START HERE — <Drive Name>
Welcome. Read this before you touch anything. (2 minutes.)

WHAT THIS DRIVE IS:   <one line>
WHO OWNS IT / ASK:    <role or group — who to ping with questions>
YOUR ACCESS:          <what your role can do here>

WHAT GOES WHERE:
   00_... → ...
   10_... → ...

HOW TO NAME FILES:
   YYYY-MM-DD_Scope_DocType_Description_vNN.ext
   (each folder has a _NAMING card with its exact types)

GOLDEN RULES:
   ✅ Start anything new by cloning from _TEMPLATES
   ✅ One file, one home — need it elsewhere? use a shortcut, not a copy
   ✅ Old drafts → 90_Archive  (never "Final-v2")
   🚫 <the one thing people get wrong in this drive>

FULL RULES:  see "Drive Organization Standard" + "Naming-Convention Cards"
```

## 1. 📌 `K·CORP·20 · Company Hub` — *everyone's first stop*

```
📌 START HERE — Company Hub (K·CORP·20)
Welcome to Kessair. This is the first drive you should read. (5 minutes.)

WHAT THIS DRIVE IS:   The company-wide knowledge base — onboarding, SOPs,
                      training, org chart, brand, and blank templates.
WHO OWNS IT / ASK:    Operations (COO)
YOUR ACCESS:          Everyone can read. Managers can add/edit.

WHAT GOES WHERE:
   01_Start-Here-Onboarding → read this FIRST — how we work, your tools
   02_SOP-Master-Library    → company-WIDE procedures (onboarding, IT, expenses)
   03_Training-Library      → recorded walkthroughs, how-tos
   04_Org-Chart-Directory   → who does what, who to ask
   05_Brand-&-Identity      → logos, brand guidelines
   06_Blank-Templates       → approved blank contracts/forms to copy

HOW TO NAME FILES:  SOP_<Company>_<Task>_vNN   (e.g. SOP_SHARED_Onboarding_v01)

GOLDEN RULES:
   ✅ Read 01_Start-Here before anything else
   ✅ Company-SPECIFIC SOPs live in your company's own Ops drive, NOT here
   🚫 NEVER put lead data, deal docs, financials, or anyone's personal info here —
      EVERYONE can read this drive.
```

## 2. 📌 `K·ACQ·30 · Marketing & Lead Data` — *data VAs & cold callers*

```
📌 START HERE — Marketing & Lead Data (K·ACQ·30)
This is the raw-records machine. Read before you touch the data. (3 minutes.)

NOTE — RECORDS ≠ LEADS:  This drive holds RAW RECORDS (scraped county data —
                      nobody has responded yet). A "lead" = someone who replied
                      and said "I want to sell"; those live in the CRM and the
                      Deal Flow drive (K·ACQ·40), NOT here.

WHAT THIS DRIVE IS:   Where raw county records land (auto), plus campaigns,
                      skip trace, market intel, buyer lists, and compliance.
WHO OWNS IT / ASK:    Data Manager (day-to-day) · Sales Manager
YOUR ACCESS:          Data VA = organize freely.  Cold Caller = ADD call notes
                      only (you can't delete or move records).

WHAT GOES WHERE:
   01_First-to-Market-Records → AUTOMATED raw records → 00_Inbox/daily (see rule below)
   02_Campaigns               → one folder per campaign (month + channel + niche)
   03_Skip-Trace-&-Enrichment → phone/skip results
   04_Market-Intelligence     → Market Finder exports, ZIP scoring
   05_Buyer-Lists             → cash-buyer research
   06_Creative-Assets         → campaign creative
   07_Compliance ⚠            → opt-outs, DNC, litigator scrubs (KEEP FOREVER)

HOW TO NAME FILES:  Campaigns → YYYY-MM_Channel-Niche_DocType_Desc
                    (each folder has its own _NAMING card)

GOLDEN RULES:
   ✅ Log call outcomes as notes on the record
   ✅ Any opt-out → copy to 07_Compliance immediately (and never delete it)
   🚫 NEVER rename, move, or delete anything in 01_First-to-Market-Records —
      the SiftStack pipeline and the DataSift upload depend on those exact names.
```

## 3. 📌 `K·ACQ·40 · Deal Flow` — *acquisitions, dispo, TC*

```
📌 START HERE — Deal Flow (K·ACQ·40)
Every live deal, lead to close, lives here. (3 minutes.)

WHAT THIS DRIVE IS:   The deal pipeline — one folder per deal, from first
                      contact through closing, plus your buyer CRM.
WHO OWNS IT / ASK:    Sales Manager
YOUR ACCESS:          Closers / Dispo / TC = full control on deals.

WHAT GOES WHERE:
   01_Pipeline        → ACTIVE deals — one folder each
   02_Closed-Deals    → finished deals, by year
   03_Dead-Deals      → dead for now, kept for follow-up
   04_Templates       → the blank deal folder you CLONE for a new deal
   05_Dispo-Buyer-CRM → buyer relationships, proof of funds

HOW TO NAME:  Deal folder → YYYY-MM-DD_Address   (e.g. 2026-07-02_123-Main-St)
              Files keep the address in the name (see the _NAMING card).

GOLDEN RULES:
   ✅ Start a new deal by CLONING 04_Templates/Deal — never build from scratch
   ✅ Work it through the numbered folders 00 → 07
   ✅ When it closes, MOVE the folder to 02_Closed-Deals/{year}
   🚫 Don't leave a closed or dead deal sitting in 01_Pipeline
```

## Applying this to the other drives

The other 14 drives (Properties, Homes, Development, Equity, and the two restricted Corporate drives) follow the **same Master shape**. When you build one:

1. Copy the Master block.
2. Fill the three top lines (*what it is · who owns it · your access*).
3. List the folders (`WHAT GOES WHERE`) straight from the Blueprint.
4. Point naming at that drive's `_NAMING` cards.
5. Add the **one 🚫 rule** that matters most for that drive (e.g. Development's *"investor docs go in DEV·65, never in the project folder"*; Equity's *"deal folders are per-team — never share outside the deal"*).

> A `00_START-HERE` doc is 10 minutes of work per drive that saves every future VA an hour of confusion — the highest-leverage thing you can put in a shared drive.
